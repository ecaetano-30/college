This leaderboard follows the same offensive and pitching framework used in the public college softball WAR model: a team’s value is broken into batting contribution, pitching contribution, and total wins above replacement. The page below adds more context than a raw table by surfacing the strongest teams, the biggest production gaps, and the same advanced WAR components visible in the underlying model.

The strongest teams on this page combine dependable offense with dependable production on the mound. In the model, those totals are built from the same run-value framework used to estimate linear weights, then translated into a standardized WAR scale so the leaderboard can be compared across teams and conferences.
